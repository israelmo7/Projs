## 📁 Projects

### 1. SoundBoard
**Location:** `/SoundBoard/`

A soundboard system with visual trigger images (1-7) used to activate specific sounds or actions in an audio processing pipeline. Contains processed PNG trigger images and the main processing script `coilmaker.py`.

---

### 2. wake_word
**Location:** `/wake_word/`

Speech recognition project focused on training models for wake word detection. Includes datasets for training, feature extraction, TTS generation, model conversion to TensorFlow Lite, live inference, **FastAPI backend**, and **React dashboard** for portfolio demos.

---

### 3. Presentation
**Location:** `/Presentation/`

Video presentation project containing stage-by-stage processing (analyzer → director → renderer) to create final video outputs. Includes source photos, video clips, stage configuration, and editing decision lists.
