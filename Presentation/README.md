# AI Video Director Pipeline

A local AI-powered video presentation generator that transforms photo albums into beat-synced videos.

## Overview

This project automates the creation of video presentations from photo collections by using AI to analyze images, generate scripts, and edit the final video.

## 3-Stage Pipeline

### Stage 1: Image Analysis
Analyzes all photos in the `photos/` directory:
- **EXIF Extraction**: Pulls datetime metadata from each image
- **Face Recognition**: Checks if the reference "star" (from `star.jpg`) appears in each photo
- **Ollama Vision Classification**: Uses LLaVA to classify images into categories:
  - `Portrait` - Individual portraits
  - `Friends/Group` - Group photos
  - `Funny` - Humor-heavy moments
  - `Childhood` - Early years photos
  - `Action/Event` - Dynamic scenes or special events

Output: `video_plan.json` containing structured metadata for all photos.

### Stage 2: AI Director
(Coming Soon)
Uses an LLM to read the video_plan.json and generate a JSON timeline/script that sequences photos logically based on:
- Chronological order
- Thematic grouping
- Emotional arc building
- Transition suggestions

Output: `timeline.json` containing the sequencing script.

### Stage 3: Video Editor
(Coming Soon)
Uses MoviePy and Librosa to:
- Load the audio track from `assets/`
- Detect beats using Librosa
- Sync photos to beat transitions
- Render the final video to `outputs/final_video.mp4`

## Directory Structure

```
Presentation/
├── photos/              # Input images (place your photo album here)
├── outputs/             # Final rendered video will appear here
├── assets/              # Placeholders, music tracks, reference images
│   ├── music/          # Audio files
│   └── star.jpg        # Reference image of the "main star" (face)
├── video_plan.json     # Generated by Stage 1 (not in git)
├── timeline.json       # Generated by Stage 2 (not in git)
├── README.md           # This file
└── stage1_analyzer.py  # Stage 1 implementation
```

## Requirements

```bash
pip install -r requirements.txt
```

## Usage

```bash
cd Presentation
python stage1_analyzer.py photos/
```

## Notes

- Ollama must be running locally with the `llava` model loaded
- Ensure `star.jpg` exists in `assets/` before running Stage 1
- The `outputs/` and `assets/` directories are gitignored
